# 🧩 LeetCode Solutions in C#
### 📖 Overview
This repository contains my solutions to various **LeetCode** problems implemented in **C#**.  
The goal is to practice algorithms, data structures, and clean coding principles while building a personal reference library.

### 📂 Structure
- Solutions are grouped by topic (Arrays, Strings, Dynamic Programming, Graphs, etc.).
- Each file is named after the problem (e.g., `TwoSum.cs`, `ValidPalindrome.cs`).
- Code is written in **C# (.NET 6/7)** with a focus on readability and efficiency.

Example:
/Arrays/TwoSum.cs /Strings/ValidPalindrome.cs /DynamicProgramming/ClimbingStairs.cs
